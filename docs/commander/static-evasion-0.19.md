# Static evasion and blocking — engine 0.19

This frozen prototype adds 146 complete source-bound creature definitions to the 1,437-definition activation build. It retains all earlier definitions, 20 separate token templates and all 63 earlier deck revisions exactly, then adds six legal development decks. The resulting release has 1,583 primary definitions and 69 legal decks; 30,246 of the pinned 31,829 eligible identities remain unsupported. Its exact source changes are composed into the main 0.20 release, whose full repository gate passed. No separate main 0.19 gate was run.

The engine now evaluates fear, intimidate, horsemanship, shadow, skulk and the five basic landwalk abilities. Printed “can't block,” “can't be blocked,” and “can block only creatures with flying” clauses have separate typed restrictions. These checks combine with existing flying, reach and menace. A block decision publishes an explicit attacker-to-eligible-blocker domain with the minimum number of blockers. The engine recomputes legality when accepting the command; a modified UI projection cannot authorize an illegal block.

Landwalk checks the actual defending player's controlled lands. Skulk compares current derived power at declaration. An accepted block remains a block if those characteristics change later. The observation-only driver follows the current block domain. Independent review reproduced and fixed a driver failure caused by iterating a historical attacker that had already left the battlefield before blockers were declared.

The independent review read all 146 complete source bodies, 30 associated rulings and 61 retained Comprehensive Rules nodes. Its 14 tests and 56 assertions use constructed full-scan rule boards. They cover cumulative restrictions, artifact and color alternatives, menace, different defenders, post-declaration changes, forged projections and departed attackers. They do not qualify source admission, prepared factories, persistence or completed games. The review records a later compiler-index change separately; the reviewed runtime and driver bytes remained unchanged.

A separate source suite actually cast 145 different authenticated cards in legal 100-card decks under three resolver configurations. It executed 435 attacker scenarios and another 132 blocker-role scenarios for 44 cards, plus two inventory/gap tests: 569 tests and 6,406 assertions. These scenarios pay printed costs and make ordinary turn, attack and block declarations, but use explicitly constructed hands and basic lands. They do not prove whole-card damage behavior or count as completed games. Storm Fleet Sprinter remains uncast in this suite because none of its 47 admitted commander profiles accepts its blue/red color identity. No legality waiver was applied.

Failed attempts remain in the archive. One source-suite attempt incorrectly expected Scryfall's generic “Landwalk” metadata category to be another executable keyword; the corrected expectation follows the printed specific landwalk ability and CR 702.14a. A combined core run passed 2,202 tests and 28,116 assertions after the activation integration. The public CLI compilation separately reproduced the exact release and deck revisions.

Two real CLI games completed in 509 and 1,692 accepted commands. Each ran independently in full-scan, prepared-scan and prepared-indexed modes, compared every semantic boundary and acting-player observation, and replayed successfully. The games resolved nine and fifteen new-source permanents respectively. Root artifact review re-executed the stored command tapes and joined source identities, receipts, event hashes and final states. Resolver repetitions are not additional unique games.

The actual two-seat game reaches a block decision involving Marsh Threader, Sun-Collared Raptor and a Swamp controlled by the defender. The four-seat game reaches Furtive Homunculus against the higher-power Zephid. Under all three resolvers, deliberately submitting each forbidden pair is rejected without changing the committed hash. The original command then advances the pending block normally.

Real browser SQLite OPFS games completed in 502 and 1,581 commands, with nine and fifteen paid new-source permanent resolutions. Every native/browser boundary matched. Separate stopped-history checks preserve the two selected block decisions and their following accepted commands across 12 reloads, 12 imports and 24 exact receipt retries. Six imports advance one command; six already contain it. These are prefixes of existing games and add no completed games. Root audit checks the raw logical saves, checksums, replay boundaries, actual source/defender facts and native prefixes.

The fixed 64-input regression completed and replayed all 16 two-seat and 48 four-seat assignments, totaling 89,784 accepted commands. Its older decks contain none of the new evasion definitions. It verifies retained behavior on those exact inputs; source-specific evidence comes from the separate executions above.
