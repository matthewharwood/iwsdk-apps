A pending placement continuation must follow the living APNAP suffix and include every unplaced cohort controller (CR 603.3b, 704.3, 800.4). Previously, a constructed contradictory controller could redirect life gain, and a reordered continuation could place constructed cohorts out of APNAP order. Logical save import independently replays every boundary, so this review did not demonstrate an import bypass.

Existing tests also cover source removal before and after placement, separate pass cycles, deferred empty-library loss, and duplicate-free checkpoint restoration.
